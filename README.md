# PanePeek

Browse and preview your documents, edit text inline, and easily share the file paths with your AI agents.

PanePeek is a native macOS 26+ app for Markdown, notes and other documents.

![PanePeek in light appearance, with a document folder and a rendered Markdown project brief in Details.](docs/screenshots/browse-preview-light.png)

## What you can do

- Browse one or two folders side by side, with sorting, hidden files and favourite folders.
- Preview Markdown, images and local videos, or use macOS Quick Look for other supported documents.
- Edit and Save text files inline with syntax highlighting.
- Copy absolute or relative paths for one file or several files at once.
- Create, rename, copy, move and trash files, with Finder drag and drop.
- Work in separate windows. PanePeek remembers the last active window's folders and layout.

![PanePeek in dark appearance, editing a Markdown research plan with syntax highlighting and an unsaved-change indicator.](docs/screenshots/inline-editing-dark.png)

See the [usage guide](docs/usage.md) for help with browsing, editing and sharing paths, along with keyboard shortcuts. Screenshots use fictional sample documents.
