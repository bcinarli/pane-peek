# Security policy

## Reporting a vulnerability

Report suspected security issues through [GitHub private vulnerability reporting](https://github.com/bcinarli/pane-peek/security/advisories/new).

If you cannot use GitHub, email [support@panepeek.app](mailto:support@panepeek.app) with “Security report” in the subject.

Please do not report vulnerabilities in public issues, discussions or pull requests.

Include, where available:

- Your PanePeek version and build number, macOS version and download source.
- Steps to reproduce the issue and its potential security impact.
- A minimal sample file or proof of concept using fictional data.

Remove credentials, private documents and sensitive paths from reports and attachments.

## Supported versions

Security fixes target the latest stable release. Older versions may require an upgrade to receive a fix.

## Coordinated disclosure

Please coordinate public disclosure with the maintainer, allowing time to investigate and make a fix available.
