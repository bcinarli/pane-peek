Getting started

Start with
a folder.

PanePeek runs on macOS 26 and later.

  1. Open a folder.

    Choose Folder from the toolbar’s Directory actions menu, or press Command-L to enter a path. Double-click folders to open them and use the path above the list to return to a parent folder.

  2. Edit a text file.

    Select a supported text file and choose Edit in Details. Make your changes while the folder stays in view, then choose Save to keep them in the file. You can also preview files in Details or press Space for Quick Look.

  3. Add a second folder when you need it.

    Choose Two Panes in the toolbar to show both folders. Click a pane to make it active; toolbar actions apply to that pane.

  4. Copy or move between folders.

    Select files or folders in one pane, then right-click and choose Copy to Other Pane or Move to Other Pane. You can also drag items between panes or between PanePeek and Finder.

Using PanePeek

Common
questions.

Which folders can I open?

Check that the folder still exists and your Mac account can read it. Use the folder chooser to try another location, and include any message from PanePeek if you email support.

How do I refresh a folder?

Click the pane and choose Refresh from the View menu, or press Command-R. This reloads the folder and the selected file’s preview after changes in Finder or another app.

Which files can I edit?

You can edit supported UTF-8 text files up to 1 MiB. Other supported files open in preview mode. If Save shows an error, your draft stays open while you check the message and the file’s write permissions.

How do I save my edits?

Choose Save to keep your edits in the file for next time. Before you leave a draft, PanePeek asks you to save or discard changes; choose Cancel to keep editing.

What if filenames match?

Copy keeps the existing file unchanged; use a different name or destination to copy the new file. For a move, use Keep Both to choose another name or Replace to overwrite a regular file. Folders use a separate name; Cancel leaves both locations as they are.

Contact

Get in touch.

To report a problem, describe what happened and the steps that led to it. Include your PanePeek and macOS versions so the issue is easier to check.

Report bugs, suggest improvements or ask a question through GitHub Issues (opens in a new tab), or send an email. Support is provided as time allows; a reply or resolution is not guaranteed.
