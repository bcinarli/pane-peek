# Writing checks

Before editing prose, apply the content boundary, ownership and Writing rules in `agent-paper-trail/README.md`. Brevity never makes excluded material eligible.

## Current project records

Lead with the current requirement, fact or decision. Use ordinary words and concrete behaviour. Keep relevant rationale and material limits; remove warmup, generic framing, repeated conclusions and discussion history. Link a fact's owner rather than restating it.

## Agent instructions

Put the first action first. State the input, action, output home and boundary when they affect execution. Keep conditions, approval gates and stop points beside their actions. Preserve exact names, paths, scope and authority while tightening. Link binding rules instead of copying them into every operation.

## Final pass

Verify source support, necessary qualifiers and the receiving agent's first action.

For example, replace “We investigated several options and eventually decided to retain the identifier” with “Retain the identifier so existing references resolve.” Include that rationale only when supported by the actual decision.
