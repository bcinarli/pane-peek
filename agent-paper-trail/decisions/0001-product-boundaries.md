# Product boundaries

Status: Superseded

The [browser UI and preview decision](2026-10-16-browser-ui-and-preview-improvements.md) supersedes the initial transfer-confirmation and collision policy. The [current spec](../specs/001-mvp/spec.md#scope-boundaries) owns product boundaries: a focused local macOS file browser, guarded file mutations and one remembered working configuration.

A narrow local workflow avoids remote account/connection management and full-session restoration. System Trash and explicit conflict/draft handling protect recoverable data. Obsolete interaction rules do not override the current spec.
