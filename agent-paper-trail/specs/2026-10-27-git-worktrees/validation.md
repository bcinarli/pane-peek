# Git and agent worktrees validation

The [spec](spec.md#acceptance-criteria) owns G1–G8. All implementation and native acceptance remains Pending. Planning approval and local research do not establish runtime feasibility. Existing release waivers do not cover this workstream.

| Criterion | Verdict | Evidence / remaining scope |
| --- | --- | --- |
| G1 Optional Apple Git | Pending | Missing/unsupported tools, no unsolicited install prompt, ordinary app availability and no added third-party runtime dependency. |
| G2 Local sandbox inspection | Pending | Real signed-app checkout/common-metadata access, read-only/no-network behaviour, bounds, cancellation and stale/error outcomes. |
| G3 Discovery and navigation | Pending | Repository registrations, Codex/Cursor/Claude/Windsurf/Hermes hints and custom locations, including Antigravity and unknown ownership; bookmarks, access boundaries, bounded cross-source deduplication, remnants and guarded navigation. |
| G4 Pane repository information | Pending | Correct branch/detached/initial state, summaries, independent panes/windows and refresh lifecycle. |
| G5 Git decorations | Pending | Mixed status, folder aggregation, nested boundaries, official palette roles and readable non-colour/selection cues. |
| G6 Unified View Diff | Pending | Labelled comparisons, glance-oriented presentation, limits, saved-draft distinction, retained editor and read-only controls. |
| G7 Worktree review facts | Pending | Local comparison/freshness, metadata and explicit activity/removal uncertainty. |
| G8 Native accessibility and distribution | Pending | Affected keyboard, VoiceOver, Light/Dark contrast, enlargement, system settings, macOS 26+ and supported sandbox package/archive paths. |

Each [task](tasks.md) links its concise evidence when implementation starts. Partial checks keep the full criterion Pending. A clean test run cannot establish manual acceptance or App Store approval.
