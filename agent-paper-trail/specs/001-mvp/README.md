The [spec](spec.md) owns the product contract. The [plan](plan.md), [task tracker](tasks.md) and [criterion matrix](validation.md) own scope, current state and acceptance. Task evidence retains current outcomes, provenance and material limits.

The reviewed sandbox units are committed; [production packaging](plan.md#production-sandbox-packaging) is accepted in [`329c026`](https://github.com/bcinarli/pane-peek/commit/329c0261ca9f64cdaa2767a46b30e8208fedaed6). The [current network and distribution decision](../../decisions/2026-10-24-github-release-updates.md) retains the shared sandbox contract; [A40](spec.md#github-release-updates) has separate implementation and acceptance. Automatic migration is outside scope; manual setup is acceptable. The 1.0.0 (7) acceptance waiver is release-specific and does not establish Store readiness.
