# Website social preview

[Editable artwork](social-preview.html) produces the [website JPEG](../../../website/assets/social-preview.jpg) at 1200 × 630 pixels. It uses the accepted [peeking-P geometry](../001-mvp/peeking-p.svg), Macchiato colours and the existing [native editing capture](../../../website/assets/app-edit-dark.png) with fictional sample files. The screenshot framing follows the website's title-bar crop. Branding and headline sit in the centre for narrower preview crops.

Serve the repository root locally, open the artwork at a 1200 × 630 viewport and export that viewport as JPEG. Verify the output dimensions, MIME type and legibility before replacing the website asset. The artwork source is outside the deployed website directory and adds no runtime dependency.

Home, Support and Privacy use the same image with individual preview titles and descriptions. [Social-preview evidence](../../specs/2026-10-17-website/evidence/social-previews.md) owns validation and remaining platform checks.
